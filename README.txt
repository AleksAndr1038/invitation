style.css — оформление и адаптация для телефона.
assets/silk.png — прикрепленная фотография шелка.
assets/glasses.png — прикрепленная фотография бокалов.
assets/fonts/ — локальные шрифты и их лицензии.

assets/black-silk.png — фон третьего блока.
